1Личность и категория
Категория задаёт «душу» страницы — символ, бейдж и ленту.
Из этого ID собирается адрес страницы и папка. Генерируется из имени — можно поправить.
2Шапка страницы
Портрет, цитата и мелодия памяти.
Имя файла ОТНОСИТЕЛЬНО папки мемориала: portrait.jpg (если в корне) или img/01.jpg (если в img/). Без «memorial/...» впереди.
Файл кладётся в папку memorial/<id>/ рядом с index.html.
3Жизненный путь
События ОТ РОЖДЕНИЯ ДО ПАМЯТИ. Порядок сверху вниз = хронология. Двигай стрелками ▲▼.
4Слова памяти
Большая эпитафия от семьи. Необязательно — если пусто, блок не покажется.
5Место покоя
Необязательно.
6Фото-, видео- и аудиоархив
Фото и видео собираются АВТОМАТОМ из папок. Песни — добавляй списком ниже и пиши им названия.
📷 Фото — клади в папку memorial/<id>/img/
🎬 Видео — клади в папку memorial/<id>/videos/
🎵 Песни — клади в папку memorial/<id>/audio/ по порядку (01.mp3, 02.mp3…)
Называй фото/видео по порядку (01.jpg, 02.jpg…). Перед загрузкой сожми фото до 300–500 КБ (TinyPNG / Squoosh).
🎵 Плейлист песен
Добавляй по одной песне. Название — что увидит семья (пиши как хочешь, по-русски). Файл можно НЕ писать — тогда песня возьмётся из audio/ по номеру в списке (1-я строка → 01.mp3, 2-я → 02.mp3…). Пиши файл только если имя другое.
